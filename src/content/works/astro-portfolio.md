# そういえばまともなマイページ作ってなかったな
見出しの通りにふと思った3年の春、大急ぎで作成したのがこのサイトです。金欠なのでGitHub Pagesで動かしてます。
就活、進学、趣味、制作実績、技術ブログ、学習記録をひとつにまとめる個人サイトになる予定です。

作品や記事は `src/content` 以下の Markdown で管理し、GitHub の Web 画面からも編集できる構成にしています。
